# 0ath CLI Wiki & Documentation

This repository hosts the official, auto-generated documentation for the `0ath-cli` orchestrator, built for the `0_ath` Microservice MMO architecture.

## Access the Documentation

The documentation is served live via GitHub Pages.

👉 **[View the Official Documentation](https://shdynila.github.io/0ath-cli-wiki/)**

## About This Repo
This repository is exclusively used for hosting the GitHub Pages Wiki. The Markdown files located in the `/docs` folder are automatically generated by the private `0ath-cli` codebase using the `cobra/doc` package.

To update this documentation, run the following command from the `0ath-cli` repository:
```bash
./0ath generate-docs
```
This will automatically rebuild the markdown files in this repository's `/docs` folder based on the latest CLI commands and flags.
